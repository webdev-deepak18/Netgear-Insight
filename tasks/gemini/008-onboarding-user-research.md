## Goal
Real user evidence of pain in Insight onboarding and setup, plus a comparison of competitors' onboarding. This backs the problem statement for Deepak's onboarding + Home redesign case study.

## Questions
A. User voice: 15–30 verbatim quotes about sign-up, adding devices, offline devices, subscriptions during setup, and app vs portal. Sources: App Store/Play reviews, community.netgear.com, Reddit. Prefer 2024–2026 and flag 10.0. Give each a URL, date, user type and theme tag.
B. 4–7 themes, each with a count, the 2 best quotes, and a severity.
C. Competitor onboarding (eero / eero for Business, UniFi, Meraki Go, Omada): the steps, QR vs serial, error handling. Then 2–3 patterns Insight could learn from, and 1 weakness per competitor.
D. Gaps: which themes need real interviews.

## Rules
Open every URL. Reddit links must contain /comments/<id>/, and community links must end /td-p/<n>. No working source means don't include it. Quotes must be word for word.

## Output format
Markdown, up to about 4,000 words. Start with a 6-line TL;DR. End with "Implications for Deepak's onboarding redesign" (3–5 bullets).
