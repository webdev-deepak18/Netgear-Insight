### Q: How do you structure design tokens and variables in Figma?

The JD names "components, auto-layout, design tokens, variables".

> "In three layers. **Primitives** are raw values, like blue-500 or space-16. **Semantic tokens** describe meaning, like color/text/primary, color/status/offline or space/card-padding, and they point to primitives. **Component tokens** only exist where a component really needs its own value. Modes sit on the semantic layer, so light and dark, or a brand theme, swap in one place. Components only ever use semantic tokens. That way a rebrand or a dark mode is a variable change, not a redesign."

**Cue card**

- 3 layers: primitive → semantic → component
- Modes (light/dark, brand) on the semantic layer
- Components use semantic tokens only
- Rebrand = a variable change, not a redesign
- Status colours always with icon + label

* Networking twist to mention: status colors like online, offline, warning and updating are semantic tokens. They should never rely on color alone, so pair each with an icon and a label for accessibility.
